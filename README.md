# 来たことある？（kitakoto）

「今いる場所に、過去来たことがあるか。いつ来たか」を調べるアプリです。Googleマップのタイムライン履歴と、写真に残った位置情報から探します。

**https://amahisa.github.io/ihbh/**

アプリを開くと、すぐ現在地で検索して結果を出します。前回の訪問日が「スタンプ」で大きく表示され、初めての場所は「はじめて」と出ます。

## 特徴

- **位置履歴は端末の外に出ません。** 読み込んだファイルはブラウザの中で解析され、その端末の IndexedDB にだけ保存されます。サーバーはなく、このリポジトリにもアプリ本体しか置いていません。
- **オフラインで動きます。** 海外旅行先でも使えます（Service Worker でアプリ本体をキャッシュ）。
- ビルド工程・外部ライブラリなし。`index.html` ひとつで動く静的な PWA です。
- 対象は Android 版 Chrome です。

## 使い方

### 1. ホーム画面に追加する

Chrome でアプリを開き、メニューから「ホーム画面に追加」します。アプリとして使えるほか、ブラウザが保存データを勝手に消しにくくなります。

### 2. タイムラインを読み込む

Android の「設定 → 位置情報 → 位置情報サービス → タイムライン → タイムラインデータをエクスポート」で `Timeline.json` を書き出し、アプリの設定（右上のアイコン）から「タイムラインを読み込む」で選びます。

読み込める形式は次のとおりです。複数のファイルをまとめて選べます。同じ記録は重複しません。

| 形式 | 内容 |
|---|---|
| `Timeline.json` | Android 端末からエクスポートしたもの |
| 旧 Takeout の Semantic Location History | `timelineObjects` を含む JSON |
| 旧 Takeout の `Records.json` | `locations` を含む JSON |
| このアプリのバックアップ | 設定の「バックアップを書き出す」で作ったもの |
| 写真由来の JSON | 下の「写真の位置情報を使う」で作ったもの |

### 3. 調べる

- 検索範囲は 100m / 200m / 500m / 2km から選べます。
- 年ごとの一覧の行をタップすると、その日の「タイムライン / Google フォト / Amazon フォト / 地点」を開けます。
- 設定から、座標を手入力して調べることもできます。

## 写真の位置情報を使う

PC や NAS にある写真の EXIF から撮影位置と日時を読み取り、アプリに読み込める JSON を作るスクリプトです。Python 3 の標準ライブラリだけで動きます。JPEG と HEIC/HEIF に対応しています。

```
python3 tools/photo_exif.py /path/to/photos [別のフォルダ ...] -o photos.json
```

できた `photos.json` を、Timeline.json と一緒にアプリへ読み込みます。アプリでは、写真だけの日は「写真 3枚」と表示され、滞在した日には滞在に加えて枚数が添えられます。

- フォルダは再帰的に探します。Synology の `@eaDir`・`#recycle` や隠しファイルは除きます。
- 位置情報と撮影日時の両方がある写真だけが対象です。
- 動画と RAW は対象外です。

## バックアップと削除

端末のストレージに余裕がないとき、ブラウザが保存データを消してしまうことがあります。設定の「バックアップを書き出す」でファイルに保存しておくと、あとから読み込みで戻せます。設定には永続保存の状態も表示されます。

「保存した記録をすべて削除」で、いつでも全記録を消せます。

## 開発

```
python3 -m http.server          # 動作確認。位置情報は localhost か HTTPS でのみ動く
python3 -m unittest discover -s tools   # 写真スクリプトのテスト
```

- ビルドツールやフレームワークは入れず、`index.html`（CSS・JS インライン）のまま保ちます。
- アプリを変更したら、`sw.js` の `VERSION` を上げてください（上げないと、端末のキャッシュが古いまま残ります）。
- 仕様の詳細（データ形式、IndexedDB の構成、UI の方針）は [CLAUDE.md](CLAUDE.md) にあります。

## 既知の制限

- 実機の `Timeline.json` と、実際の写真ではまだ十分に検証していません。形式の違いで読めない場合は、`index.html` の `iterRecords()` や `tools/photo_exif.py` を直す必要があります。
- 日付指定のリンク（Google マップのタイムライン、Amazon フォト）は公式のディープリンクがなく、動作未確認です。Amazon フォトは日付をコピーしてトップを開くだけです。
- 経度 ±180 度をまたぐ検索には対応していません。
